# Pilot onboarding checklist

- [ ] Confirm firm owner and approver.
- [ ] Record pilot scope, consent and retention decision.
- [ ] Create isolated firm and user accounts.
- [ ] Upload a fictional or approved sanitized rate-card extract.
- [ ] Review the mapping preview and correct any aliases.
- [ ] Verify each rate explicitly.
- [ ] Import one supported quotation and confirm line totals.
- [ ] Select a project and run a representative change.
- [ ] Review source evidence and unresolved questions.
- [ ] Approve only after the exact diff is correct.
- [ ] Download the PDF and compare totals independently.
- [ ] Record corrections, time, outcome and support load.
- [ ] Export or delete pilot data at the agreed end date.
