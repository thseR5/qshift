# Pilot measurement

Record one row per attempted revision:

`date | firm | project type | input language | format | request received | draft ready | clarification count | corrections | approved | PDF delivered | elapsed time | manual minutes | failure reason`

Compare Qshift with the firm's baseline for the same type of change. Do not report averages until the denominator is known. Track wrong-item, missing-change, unsupported-change and mispriced-operation counts separately. Voice transcription error rate must remain separate from scope extraction quality.
