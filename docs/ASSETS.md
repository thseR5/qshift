# Included visual and font assets

No official Qshift logo or brand files were present in the supplied repository or execution brief, so the simulator uses a plain text wordmark and does not invent a replacement logo.

The PDF font `qshift/assets/NotoSans.ttf` is the Noto Sans variable TrueType font from the [Google Fonts Noto Sans source](https://github.com/google/fonts/tree/main/ofl/notosans). It is distributed under the included SIL Open Font License in `qshift/assets/OFL.txt` and is bundled so PDF generation does not need network access.
