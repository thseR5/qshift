# Founding-firm pilot onboarding

1. Confirm the firm owner, approved contact, data-use permission and support contact.
2. Create the tenant and enroll an OWNER/APPROVER through an operator-controlled process.
3. Verify a dedicated WhatsApp test/business number and record the permitted mode.
4. Import a fictional or authorized rate card; preview mappings and manually verify rates.
5. Import an original quotation without overwriting an approved version.
6. Create/select a project and complete one sample revision.
7. Confirm the before/after review, approval audit, PDF and delivery state.
8. Record the pilot limit, retention period, opt-out route and manual fallback.

Daily operations remain in WhatsApp. The internal Studio is for support, audit and recovery.
